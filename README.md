# 人力資料庫系統

這是以 Laravel 建置的本機人力資料管理系統。系統使用 SQLite 儲存資料，並提供帳號註冊／登入、人員資料清單、Excel 匯入，以及 Excel 和 Word 匯出功能。

## 系統需求

- Windows 10／11 64 位元
- 首次設定時需要網路連線，以下載執行環境及相關套件
- 不需要事先安裝 PHP、Composer 或資料庫伺服器

## 首次啟動

1. 開啟專案資料夾的上一層目錄。
2. 雙擊 `建立本機環境.bat`。
3. 等待腳本完成環境設定、建立資料庫並啟動網站。首次執行時，Windows 可能會詢問是否允許安裝 Microsoft Visual C++ 執行元件。
4. 瀏覽器會自動開啟 `http://127.0.0.1:8000`。若沒有自動開啟，請在瀏覽器輸入該網址。
5. 第一次使用請選擇「註冊」建立帳號，再登入系統。

設定腳本會在專案上一層目錄建立 `.local-runtime`，並使用 `human-resource-app` 作為應用程式目錄。請勿在設定或執行期間移動、刪除這些資料夾。

## 日常啟動與停止

- **啟動：** 再次執行 `建立本機環境.bat`，等待瀏覽器開啟。
- **直接開啟網址：** 伺服器已啟動時，雙擊專案上一層目錄的 `開啟人力資料庫.url`。
- **停止：** 關閉啟動後出現的伺服器視窗。伺服器視窗保持開啟時，才能使用系統。
- 系統只綁定本機網址 `127.0.0.1`，供這台電腦使用。

## 系統功能

- 註冊、登入與登出本機帳號。
- 查看人員資料清單。
- 匯入 `.xls` 或 `.xlsx` 人員資料。
- 匯出人員資料為 `.xlsx` 或 `.docx` 檔案。

## 資料與備份

人員資料及帳號存放於 `database\database.sqlite`。需要備份時，請先停止伺服器，再複製這個資料庫檔案，並將備份保存於安全的位置。

## 常見問題

- **設定腳本失敗：** 確認網路可用，並查看腳本視窗顯示的錯誤訊息。若 Windows 要求管理員權限安裝 Visual C++ 執行元件，請依提示處理。
- **網站無法開啟：** 確認伺服器視窗仍開啟，並使用 `http://127.0.0.1:8000`。若 8000 埠已被其他程式使用，請先關閉占用該埠的程式，再重新啟動。
- **第一次匯入 Excel 失敗：** 匯入檔必須依序包含「員工編號、姓名、部門、職稱、電子郵件、電話、到職日期」欄位，且標題列下方至少要有一筆員工資料。只有標題的空白範本會被視為沒有資料列。姓名與員工編號不可空白；電子郵件若填寫須符合電子郵件格式；到職日期可留空，若填寫請使用有效日期（例如 `2026-11-26`）。
- **出現「伺服器未能接收檔案」：** 上傳提示會顯示 PHP 錯誤碼與對應原因；若錯誤碼是 1，代表超過 PHP 單檔限制，錯誤碼是 6 或 7 則請檢查 PHP 暫存資料夾。專案的 `建立本機環境.bat` 會建立 `.local-runtime\php\tmp` 暫存目錄，並設定 PHP 使用該目錄、單檔上限為 10 MB、整體請求上限為 12 MB。修改設定後，請先關閉舊伺服器視窗，再重新執行設定檔，讓新設定生效。此錯誤發生於 Excel 內容檢查之前，不代表網路中斷或欄位格式錯誤。
- **註冊或登入失敗：** 註冊成功後會顯示完成訊息，會員資料存放於 `database\database.sqlite`。登入時，若找不到該電子郵件會提示先註冊；若帳號存在但密碼不符，會提示密碼錯誤。若頁面出現 419，請重新載入登入／註冊頁後再送出，避免使用過期的表單或工作階段。
- **資料遺失風險：** 系統資料存在本機 SQLite 檔案；移除或覆寫 `database\database.sqlite` 會影響已儲存的資料，請定期備份。
